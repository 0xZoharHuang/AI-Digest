# Code of conduct

AI Intelligence Radar welcomes constructive participation from people with different backgrounds and
levels of experience.

## Expected behavior

- Be respectful, specific, and evidence-oriented.
- Critique ideas and implementations, not people.
- Make room for questions and clearly distinguish facts, inference, and preference.
- Respect privacy: do not post credentials, private source content, personal browser data, or private
  Wiki/log excerpts.
- Accept maintainer decisions about scope, safety, and project boundaries without harassment.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, sexualized content, sustained disruption, and deliberate
exposure of private data are not accepted in project spaces.

## Enforcement

Maintainers may edit or remove contributions, lock conversations, or temporarily/permanently restrict
participation when necessary to protect contributors and the project. For a private report, contact
the repository owner through the contact methods on the
[maintainer's GitHub profile](https://github.com/0xZoharHuang). Security vulnerabilities should use
the process in [SECURITY.md](SECURITY.md).
